# masks-parser

Инструмент, который по масочному сертификату производителя находит в каталоге компании все товары, на которые этот сертификат распространяется.

Некоторые сертификаты не перечисляют товары поимённо, а задают шаблон их артикулов — маску. Например, `4VB****` означает «артикул начинается с 4VB, дальше любые четыре цифры или латинские буквы». В сертификате HI-LEX на тросы стояночного тормоза таких масок 38. Вручную сверять с ними тысячи артикулов каталога — часы работы и риск ошибиться (перепутать «О» и ноль, не заметить русскую букву или лишний дефис). Программа делает эту сверку за секунды и объясняет каждое решение.

## Архитектурные решения

Ключевые решения и их причины описаны в [docs/adr](docs/adr):

- [0001](docs/adr/0001-reconcile-with-catalog.md) — маски сверяются с выгрузкой каталога, а не разворачиваются в список;
- [0002](docs/adr/0002-case-insensitive-names.md) — производитель и товарная группа сравниваются без учёта регистра;
- [0003](docs/adr/0003-strict-article-normalization.md) — строгая нормализация артикула без автоисправлений;
- [0004](docs/adr/0004-certificate-cross-validation.md) — перекрёстная проверка сертификата и отказ при расхождениях;
- [0005](docs/adr/0005-extensible-mask-syntax.md) — синтаксис масок задаётся при создании компилятора;
- [0006](docs/adr/0006-minimal-project-layout.md) — минимальная структура проекта.

## Что подаётся на вход

1. **Масочный сертификат** — документ Word (`.docx`). Из него программа берёт производителя, товарную группу и перечень масок из таблицы реестра. Пример: [samples/certificate_sample.docx](samples/certificate_sample.docx).
2. **Выгрузка каталога** — таблица Excel (`.xlsx`) или CSV со списком товаров компании. Нужны три колонки: «Производитель», «Товарная группа», «Артикул» (порядок любой, регистр в названиях не важен, остальные колонки игнорируются). CSV может быть в UTF-8 или Windows-1251, с разделителем `;`, `,` или табуляцией. Пример: [samples/catalog_sample.xlsx](samples/catalog_sample.xlsx).

Полный список артикулов из одних масок построить нельзя: одна маска с четырьмя звёздочками — это 1,7 млн вариантов, 38 масок — около 64 млн, и почти всех таких номеров в природе нет. Поэтому маски сверяются с реальным каталогом.

## Что и как проверяется

**Сертификат.** Маски из таблицы реестра сверяются с остальными разделами документа: с перечнем масок в тексте, с итоговым регулярным выражением, с заявленным числом масок, а производитель и группа — во всех местах, где они упомянуты. Если разделы расходятся, программа останавливается и перечисляет все расхождения — неверный сертификат не даст «тихо» неполный результат.

**Каждая строка выгрузки:**

1. **Производитель и товарная группа** должны совпадать с сертификатом (без учёта регистра и пробелов по краям).
2. **Артикул приводится к поисковому ключу**: латинские буквы — в верхний регистр, неразрывные пробелы — в обычные, пробелы по краям убираются. Исходное значение сохраняется без изменений. Ничего другого не исправляется: русская «А» не заменяется на латинскую, «О» и ноль остаются разными символами.
3. **Ключ сверяется с масками**: звёздочка — ровно один символ из `0–9` или `A–Z`, совпадать должен весь артикул целиком. Принятый артикул подходит ровно под одну маску; если масок несколько, это исключение.
4. **Если не подошёл** — определяется причина: пустой артикул, пробел или перевод строки внутри, кириллическая буква, недопустимый символ (с позицией), префикса нет в перечне, неверная длина.

## Что на выходе

Отчёт Excel из трёх листов:

- **Соответствует** — товары, на которые распространяется сертификат: номер строки в выгрузке, производитель, группа, исходный артикул, поисковый ключ и маска, под которую он подошёл.
- **Исключения** — все остальные строки с причиной, например «Кириллическая буква «А» в позиции 6» или «Другой производитель: TRW». Здесь же видны опечатки в каталоге.
- **Сводка** — итоговые цифры и количество найденных товаров по каждой маске (маски без находок тоже показаны, с нулём).

Краткие итоги печатаются и в консоль.

## Установка

Нужен Python 3.12+.

```bash
python3 -m venv .venv              # создать виртуальное окружение
source .venv/bin/activate          # активировать его
pip install -r requirements.txt    # установить зависимости
```

## Запуск

```bash
python -m masks_parser --certificate samples/certificate_sample.docx --catalog samples/catalog_sample.xlsx --output data/output/report.xlsx
```

- `--certificate` — масочный сертификат `.docx`;
- `--catalog` — выгрузка каталога `.xlsx` или `.csv`;
- `--output` — куда сохранить отчёт (по умолчанию `data/output/report.xlsx`).

Свои файлы удобно класть в `data/input/` — эта папка и `data/output/` не попадают в git. Если во входных данных ошибка, программа выводит её описание и завершается с кодом 1.

### Через Docker

```bash
docker build -t masks-parser .
docker run --rm --user "$(id -u):$(id -g)" -v "$(pwd)/data:/app/data" masks-parser --certificate data/input/certificate.docx --catalog data/input/catalog.xlsx --output data/output/report.xlsx
```

Папка `data/` подключается в контейнер; `--user` нужен, чтобы отчёт принадлежал вашему пользователю, а не root.
