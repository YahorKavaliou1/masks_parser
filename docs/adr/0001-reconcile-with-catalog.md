# 0001. Маски сверяются с выгрузкой каталога, а не разворачиваются в список

Статус: принято

## Контекст

По ТЗ на выходе нужен «полный список артикулов производителя, удовлетворяющих маске». Звёздочка в маске — один символ из 36 (`0–9`, `A–Z`). Маска `4VB****` — это 36⁴ ≈ 1,7 млн строк, 38 масок HI-LEX — около 64 млн. Почти всех этих номеров в реальности нет, и сертификат прямо оговаривает: соответствие формату не подтверждает, что позиция существует. Раздел ТЗ «Нормализация выгрузки» описывает работу именно с выгрузкой: исходный артикул, поисковый ключ, исключения.

## Решение

На вход подаются два файла: сертификат и выгрузка каталога компании. На выходе — строки выгрузки, которые подходят под маски сертификата, и исключения с причиной.

## Последствия

- Результат — реальные товары компании, и его можно сразу использовать.
- Без выгрузки программа бесполезна, и это нужно объяснить заказчику.
- Режим «развернуть маску в список» не реализован. Для коротких масок его можно добавить с ограничением объёма.
