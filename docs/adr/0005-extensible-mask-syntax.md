# 0005. Синтаксис масок задаётся при создании компилятора

Статус: принято

## Контекст

В ТЗ сказано, что маски «могут изменяться» и сильно различаются у разных производителей. Сейчас известен только синтаксис HI-LEX: `*` — один символ `[A-Z0-9]`.

## Решение

`MaskCompiler(wildcards=...)` получает словарь «символ-подстановка → класс символов regex». Остальные символы маски считаются литералами и экранируются. По умолчанию словарь `{"*": "[A-Z0-9]"}`. Каждый символ маски соответствует ровно одному символу артикула, поэтому у маски есть длина и префикс, и на них опираются причины исключений.

## Последствия

- Новая подстановка (например, `#` — только цифра) добавляется без изменения кода компилятора.
- Маски переменной длины (необязательные части, диапазоны повторов) этой моделью не покрываются. Если они встретятся, понадобится отдельный тип маски.
