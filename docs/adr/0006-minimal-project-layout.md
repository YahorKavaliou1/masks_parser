# 0006. Минимальная структура проекта

Статус: принято

## Контекст

Проект — небольшое приложение для внутреннего использования, а не библиотека для PyPI. Требование к нему — минимальность.

## Решение

- Пакет `masks_parser/` лежит в корне. Он не устанавливается и запускается как `python -m masks_parser`.
- Все зависимости в одном `requirements.txt` с точными версиями. Настройки линтера — в `ruff.toml`.
- Docker-образ копирует только пакет и зависимости.
- CI в GitHub Actions на каждый push и pull request запускает две задачи: `ruff` и `pytest`.

## Последствия

- Нет `pyproject.toml`, сборки пакета и `egg-info`. Окружение разворачивается тремя командами.
- Если проект понадобится как библиотека, упаковку придётся добавить.
